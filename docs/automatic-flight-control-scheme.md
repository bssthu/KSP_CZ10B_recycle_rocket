# 完整自动飞行控制方案

## 1. 文档状态

本文描述后续需要实现和实机验证的目标控制链，不表示当前代码已经满足要求。当前代码已知存在一级落海、10 km以下PWM和喷管夹角超过30°的问题，状态为 **未通过**。

所有数值和合格条件以[强制约束与验收基线](mandatory-mission-constraints.md)为准；环境预测按[Kerbin重力、大气与气动混合模型](ksp-physics-and-hybrid-model.md)实施。本文若与强制基线冲突，强制基线优先。

## 2. 总体状态机

```text
场景与06:00时间初始化
  → 回收船部署并稳定
  → 等待10 s
  → 一级0%点火、5 s线性爬升
  → TWR > 1.05释放TT18-A
  → 500 m～35 km渐进重力转向
  → 一级推力卸载、两级安全分离
      ├─ 二级：1 s内点火 → 首次燃烧>10 s → 入轨
      └─ 一级：零油门稳定滑行越过远地点
               → 下降后平滑转为表面逆行
               → 40 km连续入口减速至水平≤1000 m/s
               → 无动力下降 + 2～3个条件检查点
               → 连续75%标称主制动
               → 2 km 150～200/5/10门槛
               → 连续竖直末制导
               → 移动索网四点捕获
               → 弹性下挠并稳定60 s
```

一级、二级、场景观察器和捕获插件必须有清晰的控制所有权；同一时刻不能由SAS、kOS和插件同时向同一个姿态或油门通道写入互相冲突的命令。

## 3. 初始化、发射和上升

### 3.1 场景与回收船

1. 创建独立演示沙盒并推进到下一次KSC当地06:00。
2. 火箭保持在发射台中心，回收船从侧面分离并部署到按当轮轨迹规划的真实海面目标区。
3. 回收船完成位置、姿态、水面物理和DP定点稳定后开始10 s等待；加载/移动时间不能算入倒计时。
4. 船在远距离可以打包以避免浮点和双载具物理问题，但接近回收区时必须恢复真实水面物理；一级自身不能用位置瞬移完成返航。

### 3.2 一级点火和夹具释放

- 初始油门锁定0%。点火后5 s内线性且单调升到100%。
- 两个真实TT18-A继续承载一级；只有实测TWR严格大于1.05才释放，并播放原版分离动作。
- 观测器记录每物理帧的油门、实际推力和TWR，不能只记录开始/结束事件。

### 3.3 重力转向

- 约500 m开始连续转弯，到35 km时目标俯仰位于0°～15°。
- 低层稠密大气中的转向和限速以Kerbin真实动压为依据，不使用地球高度经验直接缩放。
- 分离前除正常程序转弯外不得有大幅姿态动作或增长振荡。
- 一级尽可能提供高度和水平速度，但分离时推进剂余量不得超过20%。

## 4. 分离和二级控制

### 4.1 安全分离顺序

1. 一级油门归零，并把发动机推力权限设为0%。
2. 以实际发动机推力确认卸载，而不是只等待固定时间。
3. 触发TD-25，确认一级、二级成为独立载具且距离正在增加。
4. 分离安全后恢复一级回收推力权限；二级立即取得自身控制权。

### 4.2 二级任务

- 分离后1 s内点火，沿分离前运动方向平稳飞离，不等待远地点才首次点火。
- 燃烧期间油门/推力设定严格大于10%，且有相符实际正推力。
- 首次连续燃烧严格超过10 s；首次关机时二级与一级三维直线距离严格超过10 km。
- 最终远地点95～110 km、近地点90～105 km。
- 二级kOS使用`LOCK STEERING`时关闭SAS；全任务SAS/kOS冲突计数必须为0。
- 关机逻辑按轨道目标和安全上限执行，不能反复开关制造异常声音。

## 5. 一级高空滑行和入口减速

### 5.1 越过远地点

- 分离后一级保持零油门和受控惯性姿态，用角速度阻尼抑制扰动。
- 垂直速度接近0时不得追随快速转动的速度向量。
- 确认进入下降支路后才开始平滑翻转；下降到50 km后喷管进入地表速度方向，箭体保持表面逆行。

### 5.2 40 km入口燃烧

- 下降穿越40 km时开始一次连续燃烧。
- 目标只包括：水平地速降至不超过1000 m/s，并使关机后的混合模型预测轨迹基本指向回收船。
- 达标后立即关机；不能把该次燃烧延续到低空。
- 若速度达标但落点明显不正确，判定上游规划失败，不允许靠低空长距离平移补救。

## 6. 混合模型、检查点和主制动

### 6.1 预测模型

预测器在惯性系积分位置、速度和质量：

```text
a = mu/r²重力矢量
  + KSP压力/温度/密度与DragCube基础气动
  + 无动力段在线辨识的气动残差
  + 计划推力
```

每次转换到回收船地表坐标时包含Kerbin自转。固定`9.81`、单一指数大气和固定经验阻力只能用于离线故障筛查，不能决定实机点火点。

### 6.2 无动力检查点

- 入口关机到主制动之间保持弹道下降。
- 预先声明2～3个高度检查点和预测偏差阈值。
- 只有偏差超限才在对应检查点执行一次连续修正，随后完全关机。
- 检查点之间不得点火；不得用逐帧脉冲逼近小推力。

### 6.3 主制动

- 搜索最晚可行点火点，使连续75%最大推力的标称轨迹在2 km满足150～200/5/10门槛。
- 点火后保持连续燃烧；轨迹修正可以在30°姿态约束内把油门连续提高到100%。
- 到2 km前不得在0与75%/100%之间切换，也不得再次关机滑行。
- 所有动力回收阶段的可用最大推力TWR严格大于1。

## 7. 姿态、油门和2 km硬门槛

### 7.1 30°逐帧约束

- 一级下降到50 km后，只要发动机有实际推力，就在每个物理帧检查实际姿态。
- 三维地表相对速度不低于5 m/s时，喷管轴与该速度方向夹角不得超过30.0°。
- 速度低于5 m/s时，改查喷管轴与当地铅垂向下方向，仍不得超过30.0°。
- 不存在32°容差、300 m/s检查门槛或“低速不检查”的豁免。

期望推力矢量必须先投影到允许圆锥，再计算连续油门。控制器不能先生成违规姿态，事后只靠验收器拒绝。

### 7.2 2 km状态

一级下降穿越海拔2000 m时同时满足：

```text
150 m/s <= downwardSpeed <= 200 m/s
horizontalGroundSpeed <= 5 m/s
hookToNetHorizontalError <= 10 m
verticalSpeed < 0
maximumPoweredNozzleAngle <= 30.0 deg
no low-altitude PWM
```

门槛按相邻物理帧插值；不得用低于2 km后的较好状态代替。

## 8. 2 km以下末制导

- 主要任务是连续降低下降速度并保持近似竖直轨迹，水平方向只做小幅微调。
- 油门连续调节，主制动开始后到捕获前不得反复归零；最终捕获前只允许一次计划关机。
- 建立捕获约束前垂直速度必须始终小于0，不能刹停、悬停或向上反弹。
- 1 km及500 m以下不得出现多次来回姿态超调；横向误差收敛后不得重新加速或大幅反向摆回。
- 若一级尚未处于框内，挂钩不能先下降到框顶入口以下。

## 9. 钢索随动和捕获

1. 一级进入近场后，四索逐物理帧跟踪挂钩目标。
2. 低于预先声明高度后，索口随挂钩高度线性缩小，在网面上方1 m达到最终尺寸。
3. 四挂钩全部从上方进入有效网窗且索口闭合后，才建立四个弹簧阻尼承载约束。
4. 捕获立即随真实接触生效，不能延迟后突变或允许钢索/箭体明显穿模。
5. 捕获后连续下挠到约50°承载形态，不刚性瞬停、不弹飞一级、不拉翻回收船。
6. 一级任何零件在捕获前后都不得接触海面，载具不得进入`Splashed`。

## 10. 60 s保持和验收输出

四点捕获建立后连续观察60 s。期间必须始终保持四索约束、无突然水平平移、无脱索、无下坠、无向上弹起、无触海和无回收船侧翻。

验收器不能只输出一行总PASS，必须逐项报告：

- 发射、TWR和夹具释放；
- 分离余量与防回撞；
- 二级点火、推力、燃烧时长、首次关机距离和最终轨道；
- 40 km入口燃烧和检查点关机区间；
- 10 km以下油门转换审计；
- 50 km以下所有动力帧最大夹角；
- 2 km插值门槛；
- 末段无反弹/无悬停；
- 钢索几何、四点捕获、海面接触和60 s保持。

任何未测项都是未通过。构建、离线回归、专项测试和历史`SEA_MISSION_TEST_PASS`均不能替代上述证据。

## 11. 当前实现差距

在开始下一轮实测前，至少需要修复：

- 删除主制动逐帧PWM并改为连续油门；
- 把入口燃烧明确固定在下降40 km，并在水平地速达标后关机；
- 接入混合重力/大气/DragCube预测和在线校正；
- 把喷管夹角检查扩展到下降50 km以下全部动力物理帧并严格使用30.0°；
- 把2 km水平误差门槛从旧30 m收紧到10 m，并加入150 m/s下界；
- 检查二级首次关机距离、推力设定和燃烧时长；
- 将一级触海设为立即失败，并把捕获保持期改为60 s；
- 让总PASS依赖全部强制项，而不是部分旧门槛。
