# 控制算法与日志迭代

## 1. 当前状态和原则

当前控制器尚未满足强制基线：最近观察到一级落海、10 km以下PWM以及喷管/地面速度夹角超过30°。后续迭代不能再以“最后碰到网”或单行PASS为优化目标，而要同时满足[全部强制约束](mandatory-mission-constraints.md)。

控制算法可以使用解析走廊、PID、MPC或G-FOLD启发，但必须遵守三个原则：

1. 环境预测使用[Kerbin混合物理模型](ksp-physics-and-hybrid-model.md)，不把固定重力/指数大气当成实机真值；
2. 约束在控制器内主动执行，而不是飞完后才由日志发现违规；
3. 每轮保留可复查的参数、代码差异、逐帧遥测、KSP日志和视觉证据。

## 2. 目标控制结构

```text
任务状态机
  ├─ 发射/重力转向/安全分离
  ├─ 二级独立入轨
  └─ 一级返回
       ├─ 高空惯性姿态与角速度阻尼
       ├─ 40 km连续入口减速
       ├─ 混合模型落点预测
       ├─ 2～3个条件检查点
       ├─ 连续75%标称主制动
       ├─ 2 km有限状态交接
       └─ 竖直末制导与移动钢索捕获
```

横向控制仍采用“位置误差→期望水平速度→水平加速度”，垂直控制采用有限高度/速度走廊。两者先合成为期望推力矢量，再同时执行：

- 30.0°喷管/速度圆锥；
- 75%标称、最高100%的连续推力权限；
- 2 km下降速度150～200 m/s；
- 主制动开始后禁止0/非零PWM；
- 2 km以下持续下降、无反弹和无大幅水平追逐。

不能分别限幅横向和垂直通道后直接相加，否则可能产生超过30°的合成姿态，或为横向修正额外制造向上的速度增量。

## 3. 混合预测与在线辨识

预测器使用运行时`MU/RADIUS`、KSP压力/温度/密度、DragCube/Mach基础阻力和实际质量进行前向积分。无动力时，用惯性速度变化扣除重力，更新当前Mach/迎角格点的等效`CdA`与模型残差。

每次预测至少给出：

- 关机后的落点与回收船误差；
- 到2 km的预计下降速度、水平速度和水平误差；
- 连续75%主制动的最晚可行点火时刻；
- 模型不确定度和是否仍有满足30°约束的可行解。

若40 km入口燃烧把水平地速降到1000 m/s后落点仍明显错误，应回查上升/船位/入口规划，不能把误差留给低空。

## 4. 连续油门和反PWM设计

入口燃烧、每个检查点修正和主制动都是离散任务阶段，但每一段内部油门必须连续：

- 40 km入口燃烧：一次点火、连续工作、达成1000 m/s后一次关机；
- 检查点：条件满足时一次短燃烧、一次关机；检查点之间油门恒为0；
- 主制动：一次点火，按75%规划，修正时连续提高，捕获前不反复关机；
- 2 km以下：连续调节并单调完成末段减速，捕获前只允许一次计划关机。

验收器逐物理帧记录油门并统计0↔非零转换。阶段边界以外出现重复转换即为控制缺陷，而不是“平均75%”。

## 5. 姿态约束和防振荡

控制器每帧把期望喷管轴投影到允许圆锥：

- 地表相对速度≥5 m/s：以实际速度方向为圆锥轴；
- 低于5 m/s：以当地铅垂向下为圆锥轴；
- 半角始终为30.0°，没有高速/低速豁免。

姿态命令使用角速度和指令变化率限制，长箭体响应滞后由预测器显式估计。接近网口后降低位置增益、保持速度阻尼；一旦水平状态收敛，不允许控制器重新加速到较大横速或多次反向穿越中心。

## 6. 离线回归的正确用途

`tools/simulate_controller.py` 当前使用固定`G=9.81`、单一指数密度和经验阻力。它适合快速检查：

- 控制符号和坐标轴；
- PWM、向上反弹和油门饱和；
- 明显晚点火或不可达状态；
- 低空水平振荡和捕获状态机；
- 参数变化是否破坏既有工况。

它不能证明40 km落点、DragCube阻力、2 km门槛或最终捕获在KSP实机成立。离线250/250只能写成“回归未发现这些简化模型问题”，不能写成任务通过。

## 8. 每轮迭代流程

1. 从强制基线选择一个明确失败项，记录当前实机证据。
2. 只修改解决该根因所需的参数组或逻辑；同时检查是否影响其他硬约束。
3. 构建并运行离线/专项测试，排除语法、符号、状态机和明显不可达错误。
4. 安装到KSP，执行一次不人工干预的完整任务。
5. 自动生成逐项矩阵：PASS、FAIL或UNVERIFIED；UNVERIFIED按未通过处理。
6. 复查画面中的发动机/夹具/整流外形、姿态、索网几何和捕获后60 s。
7. 只有所有条目同时通过，才允许描述为完整任务合格。

后续只有用户明确要求时才创建Git提交；普通参数迭代只保留在工作区。

## 9. 症状到根因的诊断顺序

| 症状 | 首先检查 | 禁止的掩盖方式 |
|---|---|---|
| 40 km关机后落点错误 | 船位、混合模型、入口姿态和气动残差 | 低空持续平移 |
| 主制动过早 | 可变重力、DragCube、在线`CdA`和点火搜索 | PWM降低平均推力 |
| 2 km下降速度小于150 m/s | 点火时机和垂直目标 | 关机后再自由落体反复补救 |
| 2 km水平误差/速度超限 | 入口落点和检查点阈值 | 500 m以下大角度追逐 |
| 喷管夹角超过30° | 合成矢量投影、姿态滞后、油门和指令斜率 | 放宽到32°或只查高速 |
| 低空来回摆动 | 速度阻尼、位置增益、姿态响应模型 | 增加垂直推力制造悬停 |
| 捕获后横移/落海 | 四索关节、目标锁存、海面间隙、DP约束 | 瞬移或冻结一级 |
| 二级早关机 | 点火所有权、燃料/载荷、轨道关机门槛 | 只屏蔽声音或放宽>10 s |

## 10. 历史数据的使用方式

旧开发轮曾在旧门槛下记录过四点捕获、低空较小横速和短时稳定。这些数据可用于比较控制平顺性、调试索网或定位回归，但它们没有同时验证当前2 km 150～200/5/10门槛、无PWM、50 km以下全部动力物理帧30°、二级首次关机距离、一级不触海和60 s保持。

因此历史数据只能标为“历史样本”或“专项诊断”，不得作为当前完整任务成功基线。
