Copy this directory to <KSP>/Ships/Script/cz10b and cz10b-boot.ks to
<KSP>/Ships/Script/boot. In the VAB, open the booster probe core's kOS settings,
select cz10b-boot.ks, and ensure that probe core is the craft root.

The script expects a previously launched vessel named exactly "Recovery Ship"
and prefers that vessel to carry one CZ-10B Active Cable Capture Net part.

AG10 aborts the controller. Telemetry appends to Ships/Script/cz10b/telemetry.csv.
